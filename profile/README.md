Built by a family that got tired of juggling five apps — and battle-tested by that family every day since. We run Neiliro as a hosted service at [neiliro.com](https://neiliro.com) — create your family there, 30 days free, then €4.99 a month — and the app itself is open source: one Docker container, one SQLite file per family, AGPL, free to self-host for good. What the family writes is encrypted in the browser with a key the server never holds. You never have to take our word on privacy — the code is right here.

**[neiliro/neiliro](https://github.com/neiliro/neiliro)** is the app. Start with the [roadmap](https://github.com/orgs/neiliro/projects/1), or grab a [good first issue](https://github.com/neiliro/neiliro/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22).
